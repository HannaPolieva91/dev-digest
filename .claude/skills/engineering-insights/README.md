# engineering-insights — README

**Version:** 1.1.0 (2026-11-28) · **Owner:** DevDigest team · **Type:** workflow (learnings loop)

Human-facing notes. The agent reads `SKILL.md` and `examples.md`.

Writes non-obvious lessons into the `INSIGHTS.md` of the package being worked on
(`client/`, `server/`, `reviewer-core/`, `e2e/`); the root `CLAUDE.md` session protocol
tells agents to read those files before working and to run this skill as a wrap-up.
